# SOC Monitoring and Digital Forensics Lab

## Overview

This repository documents completed academic investigations involving network monitoring, authentication activity, and Windows forensic evidence.

## Investigation Workflow

1. Review the investigation objective and preserve the available evidence.
2. Examine network and authentication activity.
3. Identify relevant hosts, accounts, timestamps, and events.
4. Correlate network findings with Windows artifacts.
5. Build an evidence-supported timeline.
6. Document findings, limitations, and recommended next steps.

## Network Analysis

- Used Zeek logs to review connections and authentication activity.
- Used Wireshark to inspect packet-level network traffic.
- Investigated repeated failed SSH authentication events.
- Correlated timestamps and communicating systems.

## Windows Forensic Analysis

- Used Autopsy to examine a Windows forensic image.
- Used RegRipper to review Windows Registry artifacts.
- Used LECmd to analyze Windows shortcut files.
- Examined Prefetch evidence for program-execution history.
- Correlated artifacts to support an investigation timeline.

## Tools

- Zeek
- Wireshark
- Autopsy
- RegRipper
- LECmd
- Windows Prefetch
- Linux and Windows logs

## Skills Demonstrated

Alert investigation, log analysis, packet analysis, Windows forensics, artifact correlation, timeline development, evidence handling, and technical reporting.
